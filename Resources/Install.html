Hey Voice

Say it. Start Voice.

Open-source community preview. This download is not notarized by Apple. It does not contain a personal Apple signing certificate. macOS may ask you to approve it before opening.

Install in three steps

  1. In the disk image, drag Hey Voice onto Applications.
  2. Eject the disk image, then open Hey Voice from Applications.
  3. If macOS says the developer cannot be verified, and you trust this GitHub release, go to System Settings → Privacy & Security → Open Anyway, then confirm Open. This approves this app only. Apple's instructions.

If macOS reports malware or a damaged app, stop and report the message. Do not disable Gatekeeper or run commands that strip security attributes.

Connect it to Voice

  1. Open Codex / ChatGPT → Settings → Voice → Voice chat hotkey.
  2. Click the new orb in the menu bar. Click the shortcut field and press the same combination.
  3. Click Enable Detection. Allow Microphone, Speech Recognition, and Accessibility for Hey Voice when asked. Return and enable again after granting Accessibility.
  4. Say “Hey Voice”. Wait for Voice to open, then give your request.

After closing a call, allow about two seconds before the next wake phrase. The companion lives in the menu bar; it has no main window or Dock icon.
